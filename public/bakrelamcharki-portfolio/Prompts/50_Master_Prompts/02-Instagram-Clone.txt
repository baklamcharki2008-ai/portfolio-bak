# MASTER PROMPT: Instagram Clone

## Project Overview
Build a full-stack Instagram clone with photo/video sharing, stories, reels, messaging, explore feed, and social features. Production-ready with millions-scale architecture patterns.

## Tech Stack
- **Frontend:** React Native (Expo) for mobile + Next.js 14 for web, TypeScript, Tailwind CSS, React Native Reanimated
- **Backend:** Node.js + Express + TypeScript, GraphQL (Apollo Server)
- **Database:** PostgreSQL (relational), ScyllaDB (activity feeds), Redis (cache + sessions)
- **Storage:** AWS S3 + CloudFront CDN for media
- **Auth:** JWT + OAuth (Facebook, Google, Apple)
- **Real-time:** WebSockets (Socket.io) + Redis Pub/Sub
- **Video Processing:** FFmpeg, AWS Elemental MediaConvert
- **Search:** Elasticsearch
- **Queue:** Bull + Redis for background jobs
- **Infrastructure:** Docker, Kubernetes, Terraform, GitHub Actions
- **Monitoring:** Prometheus, Grafana, Sentry

## Detailed Requirements

### Authentication & Authorization
- Email/password with email verification
- OAuth: Facebook, Google, Apple Sign-In
- Phone number verification (Twilio)
- JWT with refresh tokens
- Session management (multi-device)
- Account privacy (public/private)
- Two-factor authentication
- Blocked users and muted users
- Restrict mode for sensitive content

### Core Social Features

#### Feed
- Algorithmic and chronological feed options
- Infinite scroll with cursor pagination
- Like, comment, share, save actions
- Double-tap to like animation (Reanimated)
- Carousel posts (multiple images)
- Tagged users in posts
- Location tagging
- Sponsored posts in feed

#### Stories
- 24-hour ephemeral stories with photos/videos
- Story reactions, replies, and polls
- Story highlights with custom covers
- Viewed-by list with privacy controls
- Story music overlay with licensing
- Story text, drawing, and sticker tools
- Close friends story sharing

#### Reels
- Full-screen vertical video player
- Short-form video editing (trim, effects, filters)
- Audio library with trending sounds
- Green screen effect
- Text-to-speech voiceover
- Auto-generated captions
- Remix and duet features
- Reels draft saving

#### Messaging (Direct)
- One-on-one and group chats
- Message reactions, replies, and forwarding
- Disappearing messages (vanish mode)
- Media sharing with preview
- Message requests filtered by type
- Voice messages via WebRTC
- Video calling (WebRTC + TURN/STUN)
- End-to-end encryption

#### Explore
- Interest-based content discovery
- Search by user, hashtag, location
- Trending topics and hashtags
- Machine learning recommendation engine
- Suggested users and posts
- Categories for browsing

#### Notifications
- Like, comment, follow, mention alerts
- Activity digest (weekly summary)
- Push notifications via Firebase/APNs
- In-app notification center
- Notification filtering and groups
- Quiet mode scheduling

### Database Design

Core tables:
- users (profile, settings, privacy)
- posts (caption, location, tagged_users)
- post_media (url, type, dimensions, filters)
- stories (media, expires_at, highlights)
- reels (video_url, audio_id, effects)
- comments (text, mentions, replies)
- likes (polymorphic: posts, comments, stories)
- follows (follower_id, followee_id, status)
- messages, message_attachments, group_chats
- notifications (type, actor, target)
- hashtags, post_hashtags
- saved_posts, archive_posts

### API Structure (GraphQL)

```
Query {
  feed(first: Int, after: String): FeedConnection!
  user(username: String!): User
  post(id: ID!): Post
  explore(category: String): [Post!]!
  notifications: [Notification!]!
  search(query: String!, type: SearchType): SearchResult
}
Mutation {
  createPost(input: CreatePostInput!): Post!
  deletePost(id: ID!): Boolean!
  toggleLike(postId: ID!): LikeToggle!
  createComment(postId: ID!, text: String!): Comment!
  followUser(userId: ID!): FollowStatus!
  uploadStory(input: StoryInput!): Story!
  sendMessage(input: MessageInput!): Message!
}
Subscription {
  newNotification: Notification!
  messageReceived(conversationId: ID!): Message!
  storyExpired(userId: ID!): Story!
}
```
