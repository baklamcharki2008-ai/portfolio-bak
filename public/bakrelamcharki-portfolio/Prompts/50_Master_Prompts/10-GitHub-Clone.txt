# MASTER PROMPT: GitHub Clone

## Project Overview
Build a complete Git repository hosting platform with repository management, pull requests, issues, actions (CI/CD), wikis, discussions, code review, and project management boards.

## Tech Stack
- **Frontend:** Next.js 14 + TypeScript, Tailwind CSS, Shadcn UI, Framer Motion, Monaco Editor (code viewer), Zustand, React Query
- **Backend:** Ruby on Rails (or Node.js + Express + TypeScript), GraphQL + REST
- **Database:** PostgreSQL (primary), Redis (cache + sidekiq queues), Elasticsearch (code search)
- **Git Engine:** Go (git operations via libgit2/go-git), managed via Gitaly-like service
- **Storage:** S3-compatible for LFS, git objects, attachments
- **Auth:** JWT + OAuth (GitHub, GitLab, Google) + SSH key auth
- **Real-time:** ActionCable / WebSocket for live updates
- **CI/CD:** Kubernetes-native runner (custom or Knative)
- **Infrastructure:** Docker, Kubernetes, Terraform, GitHub Actions
- **Monitoring:** Prometheus, Grafana, Sentry, DataDog

### API Structure

```
REST:
  GET /repos/:owner/:repo          - Get repository
  POST /repos/:owner/:repo/issues  - Create issue
  GET /repos/:owner/:repo/pulls    - List PRs
  POST /repos/:owner/:repo/pulls   - Create PR
  POST /repos/:owner/:repo/dispatches - Trigger workflow

GraphQL:
  Query {
    repository(name: String!, owner: String!): Repository!
    pullRequest(number: Int!): PullRequest
    issue(number: Int!): Issue
    search(query: String!, type: SearchType!): SearchResult!
    viewer: User!
  }
  Mutation {
    createPullRequest(input: CreatePullRequestInput!): PullRequest!
    mergePullRequest(input: MergePullRequestInput!): MergeResult!
    addComment(input: AddCommentInput!): Comment!
    createIssue(input: CreateIssueInput!): Issue!
    addReaction(input: AddReactionInput!): Reaction!
  }
  Subscription {
    issueUpdated(repoId: ID!): IssueUpdate!
    pullRequestUpdated(repoId: ID!): PRUpdate!
  }
```

## Final Instructions
Build a complete GitHub clone with all core features. The Git service must handle millions of pushes/clones with horizontal scaling. Implement the full pull request workflow with code review. Actions/CI must support complex workflow YAML with matrix builds. The code viewer must have syntax highlighting and code intelligence. Project boards should support both Kanban and table views. Implement search that indexes both repo metadata and code content. Ensure SSH and HTTPS Git protocols work correctly with authentication. Build proper moderation and abuse prevention tools. Design the UI to match GitHub's clean, functional aesthetic.
