# MASTER PROMPT: Discord Clone

## Project Overview
Build a real-time communication platform with servers, channels, voice/video calls, text chat, screen sharing, bots, and community management features. Production-ready for millions of concurrent users.

## Tech Stack
- **Frontend:** Next.js 14 + Electron (desktop), TypeScript, Tailwind CSS, Framer Motion, Zustand, SWR
- **Backend:** Go (real-time), Node.js + Express (REST API)
- **Database:** Cassandra/ScyllaDB (messages), PostgreSQL (metadata), Redis (presence/state)
- **Real-time:** WebSocket cluster (Go), WebRTC + SFU (mediasoup)
- **Voice:** WebRTC with selective forwarding unit
- **Auth:** JWT + OAuth + MFA
- **File Storage:** S3-compatible (Cloudflare R2)
- **Search:** Elasticsearch
- **Infrastructure:** Docker, Kubernetes, Terraform, GitHub Actions
- **Monitoring:** Prometheus, Grafana, Sentry, Loki

### Database Design

Primary schemas:
- users, user_sessions, user_connections
- servers, server_members, server_roles
- channels, channel_permissions, channel_category
- messages, message_attachments, message_reactions
- threads, thread_members
- voice_states, video_streams
- invites, invite_uses
- friends, friend_requests
- audit_logs, moderation_actions
- webhooks, webhook_executions
- emojis (custom), stickers

Message storage strategy:
- ScyllaDB/Cassandra for horizontal scalability
- Partition by channel_id + time bucket
- Message IDs are time-sortable (Snowflake-like)
- Archived to S3 after 90 days

### API Structure

```
REST:
  /api/servers              - Server CRUD
  /api/channels             - Channel CRUD
  /api/messages             - Messages with pagination
  /api/users                - User profiles
  /api/invites              - Invite management
  /api/webhooks             - Webhook CRUD

WebSocket Gateway:
  Gateway Opcodes:
    0 - Dispatch (server event)
    1 - Heartbeat
    2 - Identify (auth)
    3 - Presence Update
    4 - Voice State Update
    7 - Request Members
    8 - Join Voice Channel
    9 - Leave Voice Channel
Events:
    MESSAGE_CREATE
    MESSAGE_UPDATE
    MESSAGE_DELETE
    VOICE_STATE_UPDATE
    PRESENCE_UPDATE
    TYPING_START
    CHANNEL_CREATE
    GUILD_MEMBER_ADD
    GUILD_MEMBER_REMOVE
```

## Final Instructions
Build this as a complete Discord replacement at production scale. The WebSocket gateway must handle 1M+ concurrent connections with horizontal scaling. Voice quality must match Discord's Opus implementation at <50ms latency. Implement proper moderation tools and safety features. Ensure the platform supports community servers with thousands of members. Make the UI responsive and accessible. Include comprehensive bot developer documentation.
