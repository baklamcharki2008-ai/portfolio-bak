# MASTER PROMPT: Messenger Clone

## Project Overview
Build a feature-rich instant messaging platform with real-time chat, groups, media sharing, voice/video calls, stories, games, and integrations. Designed for billions-scale traffic.

## Tech Stack
- **Frontend:** React Native (mobile) + Next.js 14 (web), TypeScript, Tailwind CSS, Framer Motion, React Native Reanimated, Zustand
- **Backend:** Erlang/Elixir (Phoenix) + Node.js (BFF layer)
- **Database:** PostgreSQL (profiles/metadata), ScyllaDB (messages), Redis (presence/sessions)
- **Real-time:** WebSocket + Phoenix Channels (Elixir) + MQTT for IoT
- **Voice/Video:** WebRTC with LiveKit (SFU)
- **Auth:** Facebook/Google OAuth + email + phone
- **Storage:** S3-compatible + CDN
- **Search:** Elasticsearch
- **AI:** ML models for smart replies, translation, content moderation
- **Infrastructure:** Docker, Kubernetes, Terraform, GitHub Actions
- **Monitoring:** Prometheus, Grafana, Sentry, CloudWatch

### Real-time Protocol

```
Phoenix Channels (WebSocket):
  Topic structure: "conversation:{id}"
  
  Events:
    "new_message"         - Incoming message
    "message_ack"         - Delivery/read receipt
    "typing_indicator"    - Typing state
    "presence_update"     - Online/offline/active
    "reaction"           - New message reaction
    "call_signal"        - WebRTC signaling
    "user_presence"      - User presence change
```

### API Structure

```
GraphQL (primary):
  Query {
    conversations(first: Int, after: String): ConversationConnection!
    conversation(id: ID!): Conversation
    messages(conversationId: ID!, first: Int, after: String): MessageConnection!
    user(username: String!): User
    search(query: String!, type: SearchType): SearchResult!
  }
  Mutation {
    sendMessage(conversationId: ID!, input: MessageInput!): Message!
    createGroup(input: GroupInput!): Group!
    addReaction(messageId: ID!, emoji: String!): Boolean!
    startCall(conversationId: ID!, type: CallType!): Call!
    uploadMedia(file: Upload!): Media!
    createStory(input: StoryInput!): Story!
  }
  Subscription {
    messageReceived(conversationId: ID!): Message!
    typingIndicator(conversationId: ID!): TypingEvent!
    presenceChanged(userIds: [ID!]!): PresenceEvent!
    callEvent(conversationId: ID!): CallEvent!
  }
```
