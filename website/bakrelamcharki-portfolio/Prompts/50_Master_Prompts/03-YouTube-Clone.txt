# MASTER PROMPT: YouTube Clone

## Project Overview
Build a complete video-sharing platform with upload, transcoding, streaming, channels, subscriptions, recommendations, comments, live streaming, and monetization features.

## Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS, Shadcn UI, Video.js/Shaka Player, Framer Motion, Zustand
- **Backend:** Node.js + Express + TypeScript, GraphQL + REST hybrid
- **Database:** PostgreSQL (primary), Redis (cache/queue), Elasticsearch (search)
- **Video Processing:** FFmpeg, AWS Elemental MediaConvert, Mux API
- **Storage:** AWS S3 + CloudFront with signed URLs
- **Auth:** JWT + OAuth (Google, GitHub)
- **Real-time:** WebSockets (Socket.io) for live chat
- **Streaming:** HLS + DASH adaptive streaming
- **Queue:** Bull + Redis for video processing pipeline
- **Infrastructure:** Docker, Kubernetes, GitHub Actions, AWS EKS
- **Monitoring:** Grafana, Prometheus, Sentry, CloudWatch
- **Testing:** Vitest, Playwright, k6

## Detailed Requirements

### Authentication & Authorization
- Google OAuth (primary), email/password
- Channel creation with custom URL
- Role-based access (admin, content mod, user)
- Creator Studio access controls
- API keys for third-party integrations
- Brand account management

### Video Pipeline

#### Upload
- Chunked upload with resumable support (tus protocol)
- Drag-and-drop with progress indicator
- Multiple simultaneous uploads
- Upload queue management
- Automatic retry on failure
- Upload from URL (import)

#### Transcoding
- Multiple resolution profiles (144p, 360p, 720p, 1080p, 4K, 8K)
- HLS + DASH output with DRM support
- Thumbnail generation (auto + custom)
- Spatial audio (Dolby Atmos pass-through)
- 360° video and VR support
- HDR video support
- Automatic caption generation (Whisper AI)
- Content moderation pipeline (frame-by-frame analysis)
- Blur and cut segments for copyright

#### Streaming
- HLS adaptive bitrate player
- Quality selector with auto mode
- Variable playback speed (0.25x - 2x)
- Picture-in-picture mode
- Background playback (audio-only)
- Keyboard shortcuts
- Chapter markers and transcripts
- 60fps and high bitrate support

### API Structure

```
REST:
  POST /api/upload/init         - Initialize upload session
  POST /api/upload/:id/chunk    - Upload chunk
  POST /api/upload/:id/complete - Finalize upload
  GET /api/video/:id            - Get video details
  POST /api/video/:id/process   - Trigger transcoding
  GET /api/channel/:id/analytics - Channel analytics

GraphQL:
  Query {
    video(id: ID!): Video
    feed(input: FeedInput!): FeedConnection!
    search(query: String!, filter: SearchFilter): SearchResult!
    trending: [Video!]!
    channel(id: ID!): Channel
  }
  Mutation {
    uploadVideo(input: VideoInput!): Video!
    deleteVideo(id: ID!): Boolean!
    createComment(videoId: ID!, text: String!): Comment!
    toggleLike(videoId: ID!): LikeStatus!
    subscribe(channelId: ID!): Subscription!
  }
  Subscription {
    liveChatMessage(liveStreamId: ID!): ChatMessage!
    viewerCount(liveStreamId: ID!): Int!
  }
```
