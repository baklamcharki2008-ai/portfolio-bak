# MASTER PROMPT: Spotify Clone

## Project Overview
Build a complete music streaming platform with millions of tracks, playlists, recommendations, podcast support, social features, offline playback, and subscription billing.

## Tech Stack
- **Frontend:** Next.js 14 (web), React Native (mobile), TypeScript, Tailwind CSS, Framer Motion, Howler.js/Expo Audio, Redux Toolkit
- **Backend:** Node.js + Express + TypeScript, GraphQL, Apollo Server, Python (ML recommendations)
- **Database:** PostgreSQL (metadata/users), Cassandra (streaming analytics), Redis (cache/sessions), Neo4j (social graph)
- **Audio Processing:** FFmpeg, AAC/OGG encoding
- **Storage:** AWS S3 + CloudFront CDN
- **Auth:** JWT + OAuth (Google, Facebook, Apple)
- **Search:** Elasticsearch
- **Billing:** Stripe + PayPal
- **Real-time:** WebSocket (collaborative playlists, friend activity)
- **Infrastructure:** Docker, Kubernetes, Terraform, GitHub Actions
- **Monitoring:** Prometheus, Grafana, Sentry, DataDog

### API Structure

```
GraphQL (primary):
  Query {
    home(feedType: HomeType!): HomePage!
    search(query: String!, type: SearchType!): SearchResult!
    playlist(id: ID!): Playlist
    track(id: ID!): Track
    album(id: ID!): Album
    artist(id: ID!): Artist
    queue: Queue!
    userLibrary: Library!
    friendActivity: [FriendActivity!]!
  }
  Mutation {
    playTrack(context: PlayContext!, offset: Int!): PlaybackState!
    pause: PlaybackState!
    next: PlaybackState!
    previous: PlaybackState!
    shuffle(enable: Boolean!): PlaybackState!
    repeat(mode: RepeatMode!): PlaybackState!
    seek(positionMs: Float!): PlaybackState!
    setVolume(volume: Float!): Boolean!
    addToQueue(trackId: ID!): Boolean!
    likeTrack(trackId: ID!): Boolean!
    unlikeTrack(trackId: ID!): Boolean!
    createPlaylist(input: PlaylistInput!): Playlist!
    addToPlaylist(playlistId: ID!, trackIds: [ID!]!): Playlist!
    followPlaylist(playlistId: ID!): Boolean!
    createCollaborativeSession(sessionInput: SessionInput!): CollaborativeSession!
  }
  Subscription {
    queueChanged: Queue!
    playbackStateChanged: PlaybackState!
    collaborativeSessionUpdate(sessionId: ID!): SessionEvent!
    friendActivityUpdate: FriendActivity!
  }
```

### Audio Streaming
- Chunked HTTP streaming with Range headers
- Adaptive bitrate (ABR) for varying network conditions
- Preloading next track (while current plays)
- Audio format: OGG Vorbis for web, AAC for mobile
- Low-latency mode for Spotify Connect
- Server-side audio processing for normalization
- CDN caching with geographic optimization
- Predictive caching (next likely tracks based on user behavior)

### Ads & Monetization (Free Tier)
- Audio ads at intervals (determined by ad server)
- Video ads on mobile
- Banner ads in browse and search
- Sponsored playlist placements
- Ad targeting based on listening habits
- Ad frequency capping
- Ad reporting and analytics

### Performance Optimization
- Lazy loading images with blur placeholders
- Virtual scrolling for library and playlists
- Infinite scroll for browse pages
- Audio context pooling
- Local caching of metadata (IndexedDB/AsyncStorage)
- Service Worker for offline assets
- Bundle splitting (route-based, lazy)

### Security
- Token-based API authentication (short-lived JWT)
- HTTPS with HSTS
- Audiobook/DRM for restricted content
- DMCA compliance infrastructure
- Rate limiting on API endpoints
- Bot detection for streaming fraud
- Privacy controls (activity broadcasts, collaborative sessions)

### Testing
- Unit: Vitest + React Testing Library
- Integration: Apollo testing + Supertest

- Audio: Sync playback test fixtures

### Docker & CI/CD
- Docker Compose for local environment

### Monitoring & Analytics

- Streaming quality metrics (buffering ratio, startup time)

- Churn prediction based on engagement

## Final Instructions
Build a complete Spotify clone with music streaming, recommendations, social features, and offline playback. The audio engine must deliver gapless playback with crossfade at 320kbps for premium users. Implement Spotify's key algorithmic features: Discover Weekly, Daily Mixes, Release Radar, and Radio. The recommendation engine must learn from listening habits in real-time. Collaborative playlists and group sessions must sync with WebRTC/WebSocket. Design the UI to match Spotify's dark theme with album art-focused design. Implement proper ad serving for free tier. Build podcast support with all playback controls.
