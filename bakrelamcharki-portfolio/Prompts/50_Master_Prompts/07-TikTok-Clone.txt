# MASTER PROMPT: TikTok Clone

## Project Overview
Build a short-form video platform with infinite scroll feed, video creation tools, effects, audio library, social features, recommendation algorithm, and live streaming.

## Tech Stack
- **Frontend:** React Native (mobile), Next.js 14 (web), TypeScript, Tailwind CSS, React Native Reanimated, MMKV (storage)
- **Backend:** Node.js + TypeScript (Express), Go (video processing)
- **Database:** PostgreSQL (profiles/metadata), ScyllaDB (feeds/interactions), Redis (cache/sessions)
- **Video Processing:** FFmpeg, AWS Elemental MediaConvert
- **ML/AI:** TensorFlow Serving, PyTorch (recommendation), Whisper (captions)
- **CDN:** Cloudflare + AWS CloudFront
- **Storage:** AWS S3 + Glacier (archive)
- **Search:** Elasticsearch
- **Auth:** JWT + OAuth (Google, Facebook, Apple, TikTok)
- **Infrastructure:** Docker, Kubernetes, Terraform, GitHub Actions
- **Monitoring:** Prometheus, Grafana, Sentry, DataDog

### API Structure

```
REST:
  /api/feed          - For You Page feed (paginated)
  /api/users/:id     - User profile
  /api/videos/:id    - Video details
  /api/upload        - Video upload
  /api/search        - Search endpoint
  
GraphQL:
  Query {
    feed(type: FeedType!, cursor: String): FeedConnection!
    video(id: ID!): Video
    user(username: String!): User
    trending(period: Period!): [TrendingItem!]!
    search(query: String!, type: SearchType): SearchResult!
  }
  Mutation {
    uploadVideo(input: VideoInput!): Video!
    likeVideo(videoId: ID!): LikeResult!
    followUser(userId: ID!): FollowResult!
    createComment(videoId: ID!, text: String!): Comment!
    startLiveStream(input: LiveInput!): LiveStream!
  }
  Subscription {
    liveViewerCount(liveId: ID!): Int!
    newLiveGift(liveId: ID!): GiftEvent!
  }
```

### Video Processing Pipeline
- Ingest: Chunked upload with resumable support
- Transcoding: H.264, H.265, VP9 for web
- Resolutions: 360p, 480p, 720p, 1080p, 4K (select videos)
- Adaptive bitrate: HLS packaging
- Thumbnail generation: 1 frame per second
- Content moderation: NSFW, violence, hate speech detection
- Copyright check: audio fingerprint matching
- Caption generation: Whisper ASR
- Watermarking: TikTok-like username watermark

### Performance Optimization
- 3-video preload buffer (native player)

- CDN with regional edge servers
- Database query optimization (indexes, denormalization)

## Final Instructions
Build a complete TikTok clone at production scale. The video feed must load instantly with near-zero buffering through intelligent preloading. Implement the FYP recommendation algorithm with real-time personalization. Video creation tools must include all TikTok effects (green screen, duet, stitch, AR filters). Live streaming must support thousands of concurrent viewers with gift system. Ensure the app works flawlessly on low-end devices with 2GB RAM. Monetization system must handle Creator Fund payouts and virtual currency. Make the UI addictive with TikTok's exact gesture controls and animations.
